## API Revendeur

Utilisez l'API Revendeur pour automatiser la gestion des licences depuis vos
propres systèmes : créer une clé lorsqu'une commande est payée, la suspendre
après une rétrofacturation ou la mettre à jour lorsqu'un abonnement change.
